# Ishibashi / Handai-mae

阪急 石橋阪大前駅とその周辺を、四角く切り出した地面のブロックとして再現した3Dジオラマ。
ブラウザだけで動きます。

▶ **Demo:** https://waya314.github.io/Ishibashi-stage/

## できること
- 朝・昼・夕方・夜の時間帯切り替え
- 電車の運行、踏切、高架道路の信号と渋滞
- 商店街のアーケード、地下道、地層の断面
- 環境音（電車・踏切・カラス・17時のチャイム）

## 操作
ドラッグで回転 / ホイール・ピンチでズーム / 2本指でパン

## 技術
Three.js（CDN）単一HTML
